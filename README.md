# DAU Pulse

AI Campus Issue Intelligence Platform

DAU Pulse is a student-first platform that helps universities understand and resolve recurring campus problems faster. Students can report issues through simple channels such as a web form, QR code, or WhatsApp-style interface, while administrators get an AI-powered dashboard that groups similar complaints, detects urgency, and highlights the problems that need action first.

## Problem

University students often face repeated campus issues such as hostel maintenance problems, Wi-Fi failures, cafeteria complaints, transport delays, academic confusion, and administrative follow-up delays.

Today, these issues are usually scattered across WhatsApp groups, emails, verbal complaints, Google Forms, or class representatives. As a result:

- Student complaints get buried or repeated many times.
- Administrators do not get a clear view of recurring patterns.
- Urgent issues may not be prioritized early.
- There is limited data for improving campus operations.

## Solution

DAU Pulse converts scattered student feedback into structured campus intelligence.

The system allows students to submit issues in natural language. An AI layer then classifies the issue, detects urgency, groups similar reports, summarizes trends, and presents a priority view for university teams.

## Key Features

### Student Side

- Simple issue reporting flow
- Mobile-friendly interface
- Category, location, urgency, and optional description
- Ticket/status tracking
- Feedback after resolution

### Admin Side

- Live dashboard of reported issues
- AI-powered issue classification
- Similar complaint clustering
- Priority scoring based on urgency and frequency
- Department/location-wise filters
- Weekly AI-generated summary reports

### AI Capabilities

- Complaint classification
- Duplicate and similar issue detection
- Urgency and severity scoring
- Sentiment analysis
- Pattern summarization
- Escalation risk prediction

## Example Use Cases

- Hostel students report repeated water or Wi-Fi issues.
- Cafeteria complaints are grouped and summarized for operations staff.
- Transport delays are tracked by route and time.
- Academic confusion around deadlines or schedules is detected early.
- Admin teams receive a weekly priority report instead of reading scattered messages manually.

## Tentative Tech Stack

- Frontend: React / Next.js
- Backend: Node.js or FastAPI
- Database: PostgreSQL / Supabase
- AI Layer: LLM-based classification, summarization, and embeddings
- Hosting: Vercel, Render, or Supabase
- Future Integration: WhatsApp Cloud API

## Expected Impact

DAU Pulse aims to reduce the gap between student problems and university action.

Expected outcomes:

- Faster identification of recurring campus issues
- Better prioritization for administrative teams
- Reduced manual complaint sorting
- Improved student satisfaction
- Data-driven campus decision-making
